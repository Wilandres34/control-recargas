# Control Recargas – app para el celular

Esta carpeta convierte tu app de Google Apps Script en una app que se instala en el celular con su propio ícono.

1. Abre `index.html` y en la línea marcada con ▼▼▼ pega el enlace de tu aplicación web de Apps Script (el que termina en `/exec`).
2. Sube todos estos archivos a un repositorio de GitHub llamado `control-recargas`.
3. En el repositorio: Settings → Pages → Branch: `main` → Save.
4. Abre `https://TU-USUARIO.github.io/control-recargas/` en el celular y agrégala a la pantalla de inicio.
